# SK Inspire Foundation Website

This repository contains a responsive, modern landing page for SK Inspire Foundation.

## Features
- Mission-focused homepage
- About, programs, impact, and stories sections
- Donation and volunteer call to action
- Mobile-friendly responsive layout
- No build required — works directly in a browser

## Run locally
Open `index.html` in a browser, or serve the project with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
